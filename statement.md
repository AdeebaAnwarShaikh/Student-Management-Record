# Student Record Management System

## Project Statement

The Student Record Management System is a Python-based project developed to make it easier to manage student information in one place. The system is designed to store basic student details such as roll number, name, course, and marks.

The main aim of this project is to reduce the difficulty of maintaining student records manually and provide simple operations for managing the information.

## Main Features

- Add a new student
- Search students by roll number or name
- Add or update subject marks
- Calculate the student's average marks
- Assign grades based on the average
- Check whether a student has passed or failed
- View a student's result
- Display all student records
- Delete a student record
- View basic class performance and analytics
- Save and load student records
- Use a simple graphical interface through Tkinter

## How the System Works

The user can first add a student by entering the roll number, name, and course. Marks can then be added for different subjects. The system calculates the average and grade automatically and shows the student's result status.

The search feature helps the user find a particular student quickly. The result section displays the student's details, marks, average, grade, and pass/fail status. Class analytics gives a simple overview of the available student results.

The project also includes a graphical user interface, making the system easier to use through buttons, a table, search box, and separate windows.

## Technologies Used

- Python
- Tkinter
- File handling
- Classes and functions
- Data storage

## Project Goal

The main goal of this project is to create a simple and practical student management application while applying basic Python programming concepts in a real-world type of problem.
